**K — for *knackered*.**

One letter for a day that left nothing in the tank: up before the alarm,
running on fumes by lunch, asleep on the sofa before the kettle boiled.
Knackered is the whole report — a sharp picture, a laugh, and an honest
day — and K is its initial. The entry is exactly one character, the letter
K, and nothing else.

## Run it

```sh
node main.ts
```

This writes the single letter `K` to `/output/entry.txt`.
